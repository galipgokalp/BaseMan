# Terimler Sözlüğü

- Base: Coinbase ekosistemi üzerinde EVM uyumlu L2 ağ.
- Sepolia: Ethereum test ağı, Base Sepolia testnet‘i referans alınır.
- OnchainKit: @coinbase/onchainkit UI ve cüzdan/işlem yardımcıları seti.
- Paymaster: Gas sponsorluğu sağlayan servis/akıllı sözleşme sistemi (ERC‑4337).
- Bundler: ERC‑4337 userOperation’ları paketleyip zincire ileten servis.
- ERC‑4337: Hesap soyutlama standardı; userOperation akışı ile çalışır.
- EIP‑7702: EOA’ların geçici olarak sözleşme davranışı sergilemesini tanımlar.
- Farcaster Mini App: Farcaster istemcileri içinde çalışan web tabanlı mini uygulamalar.
- Manifest: Mini App yapılandırma dosyası (schema, izinler, metadata).
- Embed: Mini App’in linklendiği sayfalara eklenen meta etiketleri.
- Viem/Wagmi: Ethereum istemci ve React hook ekosistemi.
- UserOp: userOperation nesnesi, ERC‑4337 işlem türü.
